# Changelog

## 0.1.0

- Add the native macOS status item with per-space controls.
- Add yabai discovery, version validation, space querying, and focus commands.
- Add event-driven refresh through owned yabai signals and a Unix-socket helper.
- Add Settings, diagnostics, config reload, reconnect handling, and launch at login.
- Add unit and integration coverage for core behavior.
- Disable workspace clicks without changing their appearance when macOS 27 uses the known-broken SIP-enabled focus path in yabai 7.1.25 or older.
- Add a native macOS app icon built around a simple lowercase `y` mark.
- Add drag-to-Applications DMG packaging and SemVer-tagged GitHub releases.
